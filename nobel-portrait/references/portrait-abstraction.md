# 从照片到手绘：形体概括原则

本说明通过文字描述摄影细节如何转为手绘形状，无需示范照片或手绘参考图。

| 照片中的信息 | 手绘中的处理 | 保留与简化原则 |
|---|---|---|
| 零散细发丝、深浅发色 | 少数宽弧形黑墨发束，间隔纸白，边缘有干刷 | 保留发型方向和轮廓，合并细发丝，不逐根还原 |
| 连续肤色与柔和光照 | 纸白脸面，少数金赭短弧、窄带与阴影块 | 保留主要结构，省略无助于识别的连续明暗 |
| 低对比的五官边界 | 眼睑、鼻孔、鼻翼、唇缘、下颌有明确墨线 | 增强关键结构的可读性，不描满皮肤起伏 |
| 自然眼睛 | 小面积金赭虹膜、黑瞳和纸白眼白，或用户指定的原眼色 | 保留眼形、眼距和目光，不统一放大眼睛 |
| 皱纹、毛孔和肤色变化 | 仅保留必要年龄线索 | 舍去照片皮肤纹理，不人为年轻化或变老 |
| 深色衣服、面料与花纹 | 少量墨线交代衣领、肩部和主要配饰，内部大片纸白 | 保留服装类别与领口，省略非必要面料纹理和花纹 |
| 彩色背景和摄影质感 | 跨背景与未着色部位的均匀细纸纹 | 替换背景，纸纹不成为脸部新增的毛孔、色斑或胡茬 |

手绘允许自然的轮廓概括，但眼距、脸型、鼻形、嘴形和表情应仍使人可辨认。不要统一加宽脸、加长颈部、强行左右对称或改变姿势。

对目标人物依次抽取脸型和五官相对关系、表情与目光、发型与配饰、服装主要轮廓。决定哪些需要墨线、哪些适合少量金赭、哪些应留纸白，先保留辨识特征，再减少描绘元素。

用户额外提供成对示例时，分别注明“当前人物身份”“转换示范原照”“转换示范结果”，禁止迁移示范人物的脸。没有示例时按文字规则直接执行。

验收时先看纸白、黑墨与金赭的整体形状，再看局部细节。满头细碎发丝、口周照片式颗粒、全脸金色渲染，即使配色正确也不能算达到所需的概括程度。
