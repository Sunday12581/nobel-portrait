# 诺贝尔肖像馆 · Nobel Portrait

将人物照片转绘为黑墨、金赭与暖白纸底的手绘肖像，
并按需生成配套的单人物介绍网页。

## 功能

- 照片转绘，保留人物长相、表情、发型与姿势。
- 生成单人物介绍网页，支持选择奖项和填写人物资料。
- 导出肖像、离线网页与转换提示词。

## 安装

在 Codex 中输入：

$skill-installer 从 https://github.com/Sunday12581/nobel-portrait/tree/main/nobel-portrait 安装技能，安装名称为 nobel-portrait。

## 使用

附上人物照片，然后输入：

$nobel-portrait 将这张照片转换为诺贝尔风格肖像，
并制作介绍网页。我希望获得诺贝尔化学奖。

## 环境要求

图像转绘需要可用的图像生成或编辑工具。
网页构建需要 Python 3，PNG/JPG 导出需要 Pillow。
